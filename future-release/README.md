# Skills for a future release

Finished skills that are not published yet, because their feature is not live in the webapp.
Nothing in this folder is built, packaged, listed in the catalog or installed.

- `dita-translation/` — DITA map translation. To release: move it back to the repo root, add
  it to sync-lib.sh, the plugin manifest and the README table, register the DITA MCP tools on
  the server again (server `src/core/mcp/future-release/`), and regenerate scripts/mcp-tools.json.
